# Overall status

Read the `status.md` files in `projects/`, the latest entries in `journal/achievements.md` and the development plan in `profile/goals.md`. The files may use English or Spanish labels (e.g. "Current phase" / "Fase actual", "Next decision I need from you" / "Próxima decisión que necesito de ti"); read both.

Reply in the language set in `settings.json` (`language`, default English), or in the language the person writes in, using this format, briefly:

**Projects**
| Project | Phase | Next decision |
|---|---|---|

**Waiting for your answer**: list of pending questions or approvals.

**Recent achievements**: the last 3-5 bullets.

**Development**: the current commitment from the plan and when the next review with `/mentor` is due.

**Suggestion**: one single recommended action for today.
